# ระบบสั่งกาแฟจากที่โต๊ะด้วย QR Code

> สร้างเมื่อ 2026-08-07

## ความต้องการ (Requirement)

ลูกค้าที่เข้ามาในร้านกาแฟสามารถสั่งเมนูได้เองจากที่โต๊ะ โดยไม่ต้องเดินไปสั่งที่แคชเชียร์ ระบบครอบคลุมตั้งแต่การสั่ง การชำระเงิน ไปจนถึงระบบสมาชิก/สะสมแต้ม และแจ้งออเดอร์ไปยังบาริสต้าแบบเรียลไทม์

รายละเอียดตามคำตอบที่ยืนยันกับผู้ใช้:

- **ขอบเขต**: ครบวงจร — สั่งเมนู, ชำระเงินออนไลน์ในระบบเลย (ไม่ต้องเดินไปแคชเชียร์), และมีระบบสมาชิก/สะสมแต้ม
- **วิธีเข้าถึงที่โต๊ะ**: ลูกค้าสแกน QR Code ที่ติดไว้ประจำโต๊ะ เปิดเป็นหน้าเว็บสั่งของทันที (ไม่ต้องติดตั้งแอป)
- **การแจ้งออเดอร์**: ออเดอร์ที่สั่งเข้ามาแสดงผลบนจอในร้าน (Kitchen Display System - KDS) ให้บาริสต้าเห็นแบบเรียลไทม์

## Scope

- ทำ:
  - หน้าเว็บสั่งเมนู เข้าถึงผ่านการสแกน QR Code ต่อโต๊ะ (ระบุเลขโต๊ะอัตโนมัติจาก QR)
  - ตะกร้าสั่งซื้อ + ชำระเงินออนไลน์ในระบบ
  - ระบบสมาชิก/สะสมแต้มสำหรับลูกค้า
  - จอแสดงผลออเดอร์ (KDS) สำหรับบาริสต้า/ครัว อัปเดตแบบเรียลไทม์
- ไม่ทำ (ยังไม่อยู่ใน scope รอบนี้):
  - แอปมือถือเฉพาะของร้าน (ใช้เว็บผ่าน QR เท่านั้น)
  - ระบบจัดการหลังบ้านอื่น ๆ ที่ไม่เกี่ยวกับการสั่ง/จ่าย/สะสมแต้ม เช่น บริหารสต๊อกวัตถุดิบ (รอวิเคราะห์แยกในเอกสารอื่น)

## User Stories / Use Cases

- ในฐานะลูกค้า ฉันต้องการสแกน QR Code ที่โต๊ะ เพื่อเปิดเมนูและสั่งกาแฟได้เองโดยไม่ต้องรอพนักงาน
- ในฐานะลูกค้า ฉันต้องการชำระเงินผ่านระบบได้ทันทีหลังสั่ง โดยไม่ต้องเดินไปจ่ายที่แคชเชียร์
- ในฐานะลูกค้าที่เป็นสมาชิก ฉันต้องการให้ยอดสั่งซื้อถูกนับเป็นแต้มสะสมโดยอัตโนมัติ
- ในฐานะบาริสต้า ฉันต้องการเห็นออเดอร์ใหม่ที่ลูกค้าสั่งจากโต๊ะ ปรากฏบนจอ KDS ทันทีที่มีการชำระเงินสำเร็จ

## Business Rules / เงื่อนไข

- 1 QR Code ผูกกับ 1 หมายเลขโต๊ะ ระบบต้องรู้ว่าออเดอร์มาจากโต๊ะไหน
- ออเดอร์จะถูกส่งไปแสดงบน KDS ก็ต่อเมื่อการชำระเงินสำเร็จแล้วเท่านั้น
- แต้มสะสมคำนวณจากยอดชำระที่สำเร็จเท่านั้น (เงื่อนไขอัตราการสะสมแต้ม/การใช้แต้มยังไม่กำหนด — ต้องระบุในรอบถัดไป)

## ประเด็นที่ยังไม่ชัดเจน (รอตัดสินใจในรอบถัดไป)

- ช่องทางชำระเงินที่รองรับ (พร้อมเพย์ / บัตรเครดิต / วอลเล็ต ฯลฯ)
- อัตราการสะสม/แลกแต้มสมาชิก
- การจัดการกรณีชำระเงินไม่สำเร็จ หรือลูกค้าต้องการยกเลิกออเดอร์หลังสั่งแล้ว
