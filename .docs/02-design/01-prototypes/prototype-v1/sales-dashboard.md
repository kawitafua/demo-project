หน้าจอนี้เข้าถึงได้เฉพาะผู้ใช้ที่มีบทบาท "เจ้าของร้าน" หรือ "พนักงานที่ได้รับสิทธิ์ดูรายงาน" เท่านั้น (`DASH-05`) จึงมี 2 state หลัก: **Authorized View** (เห็นข้อมูลยอดขาย) และ **Access Denied View** (ไม่มีสิทธิ์) — ดูทั้งสอง state ด้านล่าง

---

### Sub-state: Export Confirm Modal (เมื่อกดปุ่ม "Export CSV/Excel")

```
              +-----------------------------------------+
              |  ยืนยันการ Export ข้อมูลยอดขาย              |
              |  --text-h2--                             |
              |                                           |
              |  ระบบจะ export ข้อมูลตามตัวกรองที่          |
              |  เลือกอยู่ในขณะนี้ (ช่วงวันที่ 01 ส.ค. -      |
              |  29 ส.ค. 2026) เป็นไฟล์ CSV/Excel          |
              |  --text-body--                            |
              |                                           |
              |          [ยกเลิก]   [ยืนยัน Export]         |
              +-----------------------------------------+
```
- Modal ใช้ `--radius-lg` กึ่งกลางจอ + overlay ตาม Design System หัวข้อ 3.1
- เมื่อยืนยัน export สำเร็จ → บันทึก audit log เหตุการณ์ `data.exported` (นอก scope UI ของ prototype นี้ อ้างอิง `AUDIT-01` เพื่อเชื่อมโยง context เท่านั้น ไม่ได้อยู่ใน scope การสร้างหน้าจอรอบนี้)

## Wireframe — State 2: Access Denied View (ผู้ใช้ไม่มีสิทธิ์)

```
+--------------------------------------------------------------------------------+
| [Wordmark: my-coffee-store]                          สวัสดี, คุณ___ (staff) [ออกจากระบบ] |
+--------------------------------------------------------------------------------+
|                                                                                  |
|                                                                                  |
|                          [ไอคอน lock, สีกลาง --color-text-secondary--]              |
|                                                                                  |
|                    คุณไม่มีสิทธิ์เข้าถึงหน้านี้                                            |
|                    --text-h1--                                                  |
|                                                                                  |
|          หน้า Dashboard ยอดขายจำกัดเฉพาะเจ้าของร้าน หรือพนักงาน                          |
|          ที่ได้รับสิทธิ์ดูรายงานเท่านั้น หากต้องการเข้าถึง                                 |
|          กรุณาติดต่อเจ้าของร้าน                                                       |
|          --text-body--, สี --color-text-secondary--                              |
|                                                                                  |
|                          [กลับหน้าหลัก]                                            |
|                                                                                  |
+--------------------------------------------------------------------------------+
```
- ใช้ Access Denied State component ตาม Design System หัวข้อ 3.4 — ไม่ใช้โทน error สีแดงจัด เพราะไม่ใช่ "ความผิดพลาด" ของผู้ใช้ แต่เป็นเรื่องสิทธิ์
- เชื่อมโยงกับ business rule ที่ต้องบันทึก audit log ทุกครั้งที่ login เข้า dashboard (`AUDIT-01`, Journey 3 ขั้นตอน 1) — การตรวจสอบสิทธิ์เกิดหลัง login เสมอ

## ประเด็นที่ยังไม่ยืนยัน (สืบทอดจาก requirement ต้นทาง — ยังไม่ใช่การตัดสินใจใหม่ของ prototype นี้)

- รายละเอียดการกำหนดสิทธิ์/บทบาทผู้ใช้ (ใครกำหนดสิทธิ์พนักงาน, กี่ระดับสิทธิ์) — wireframe นี้แสดงเพียง 2 role ตัวอย่าง (owner/staff) ตามที่สเปคระบุ ยังไม่ใช่ UI จัดการสิทธิ์
- รูปแบบ/คอลัมน์ที่ต้องมีในไฟล์ export CSV/Excel — ยังไม่ระบุในสเปค จึง wireframe เฉพาะปุ่ม+modal ยืนยัน ไม่ได้ลงรายละเอียดคอลัมน์ในไฟล์ export จริง
- ชนิดกราฟเพิ่มเติมนอกจากกราฟแท่ง (เช่น pie chart สัดส่วนเมนู) ยังไม่ยืนยัน — wireframe นี้ทำเฉพาะ bar chart ตาม scope ที่ยืนยันแล้ว
