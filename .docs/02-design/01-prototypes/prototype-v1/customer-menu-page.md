# หน้าสั่งเมนูลูกค้า (QR Ordering — mobile)

> สร้างเมื่อ 2026-08-29
> อ้างอิง Design System: [[../20260829-02-design-system|20260829-02-design-system]] (หัวข้อ 2.1-2.6 Design Tokens, 3.1 Components ร่วม, 3.2 หน้าสั่งเมนู (mobile), 4.2 Mobile-first, 4.4 ความชัดเจนของสถานะ)
> อ้างอิง Requirement: [[../../../01-requirements/01-spec/20260807-01-table-qr-ordering|20260807-01-table-qr-ordering]]
> อ้างอิง Feature: `QR-01`, `QR-02`, `QR-03`, `AUDIT-05` (ดู [[../../../01-requirements/02-plan/20260829-01-feature-list|20260829-01-feature-list]]) / Journey step: [[../20260829-01-user-journeys#Journey 1: ลูกค้าสั่งกาแฟผ่าน QR Code|Journey 1: ลูกค้าสั่งกาแฟผ่าน QR Code]]

หน้าจอนี้เป็น entry point เดียวของระบบสั่งซื้อทั้งหมด (`QR-01`) เข้าถึงผ่านการสแกน QR Code ประจำโต๊ะ ไม่ต้องติดตั้งแอป ออกแบบแบบ **mobile-first** ตาม Design System หัวข้อ 4.2 (ปุ่มสำคัญอยู่ใน thumb zone, touch target ขั้นต่ำ 44×44px, ไม่พึ่ง hover)

รอบนี้ครอบคลุม 4 state ตามลำดับ flow ใน Journey 1: **(1) เมนูหลัก → (2) ตะกร้า/Checkout → (3) สมัครสมาชิก + Consent (ทางเลือก) → (4) ผลการชำระเงิน** — ไม่รวมจอ KDS (`QR-04`) และหน้า Dashboard ซึ่งอยู่นอกขอบเขตของรอบนี้

+----------------------------------+
| [กาแฟร้อน][กาแฟเย็น][ชา][ของทานเล่น] >  <-- Category Tabs (scroll แนวนอน, tab เลือกอยู่ = --color-brand-primary--)

|  | --text-body-- medium    |       |

|  +------------------------+       |
|                                    |
|  +------------------------+       |
|  | [รูปเมนู]                |       |
|  | อเมริกาโน่ร้อน            |       |

|  +------------------------+       |
|                                    |
|  +------------------------+       |
|  | [รูปเมนู]                |       |
|  | คาปูชิโน่                |       |
|  | ฿ 65                (+) |       |
|  +------------------------+       |
|                                    |
|            (scroll ต่อลงไป)          |

- Table Indicator ค้างอยู่ด้านบนสุดตลอดเวลาที่ลูกค้าอยู่ในหน้าสั่งเมนู เพื่อความมั่นใจว่าออเดอร์ไปโต๊ะถูกต้อง (business rule: 1 QR = 1 หมายเลขโต๊ะ)
- Floating Cart Bar อยู่ในระยะเอื้อมนิ้วโป้ง (thumb zone) ตาม Design System หัวข้อ 4.2 — กดแล้วเปิด State 2

## Wireframe — State 2: ตะกร้า/Checkout Drawer

```
                (overlay เข้มโปร่งแสงด้านบน State 1)
+----------------------------------+
|  ตะกร้าของคุณ              [ปิด X] |  <-- Bottom Sheet (--radius-lg--, เต็มความกว้างจอ)
+----------------------------------+
|                                    |
|  ลาเต้ร้อน                          |
|  ฿ 65        [-]  2  [+]   ฿ 130  |
|  ------------------------------   |
|  อเมริกาโน่ร้อน                     |
|  ฿ 55        [-]  1  [+]   ฿ 55   |
|  ------------------------------   |
|                                    |
|  ยอดรวม                    ฿ 185   |  <-- --text-h2-- เด่น
|                                    |
|  [ ] ฉันเป็นสมาชิกอยู่แล้ว (เข้าสู่ระบบ) |
|  ยังไม่เป็นสมาชิก? [สมัครสมาชิก] หรือ  |

|                                    |
|  +------------------------------+ |
|  |        ชำระเงิน ฿ 185          | |  <-- ปุ่ม Primary เต็มความกว้าง (thumb zone)
|  +------------------------------+ |
+----------------------------------+
```

- ปุ่มปรับจำนวน `[-]`/`[+]` ขนาด touch target >= 44×44px ตาม Design System หัวข้อ 4.2
- ทางเลือก "สมัครสมาชิก" เปิด State 3, "สั่งแบบไม่เป็นสมาชิก" หรือ "ฉันเป็นสมาชิกอยู่แล้ว" ข้ามไป State 4 ตรง (ตาม Journey 1 branch D/F)
- กด "ชำระเงิน" ไปต่อที่ State 4 (Payment Processing → Result)

## Wireframe — State 3: สมัครสมาชิก + Consent (ทางเลือก)

```
+----------------------------------+
|  สมัครสมาชิก               [ปิด X] |  <-- Bottom Sheet (--radius-lg--)
+----------------------------------+
|                                    |
|  เบอร์โทรศัพท์                      |
|  [__________________________]     |
|                                    |
|  ชื่อ (สำหรับเรียกรับเครื่องดื่ม)      |
|  [__________________________]     |
|                                    |
|  ------------------------------   |
|                                    |
|  [ ] ฉันยินยอมให้เก็บ/ใช้ข้อมูล       |  <-- Membership/Consent Checkbox
|      ตามที่ระบุใน                   |      (แยกจากปุ่มยืนยันชัดเจน)
|      [อ่าน privacy notice]          |      (ลิงก์เปิด modal/หน้าแยก)
|                                    |
|  +------------------------------+ |
|  |       สมัครสมาชิก (disabled)   | |  <-- disabled จนกว่าจะติ๊กยินยอม (AUDIT-05)
|  +------------------------------+ |
|                                    |
|  [ข้ามไปสั่งแบบไม่เป็นสมาชิก]         |
+----------------------------------+
```

- ปุ่ม "สมัครสมาชิก" ต้อง **disabled** จนกว่าจะติ๊กยินยอม consent — ตรงตาม business rule ของ `AUDIT-05` ("ถ้าไม่กดยินยอม ระบบต้องไม่สร้างบัญชีสมาชิก") และตรงกับ Journey 1 branch G ("กดยินยอม Consent" → ไม่กดยินยอม = ระบบไม่สร้างบัญชี)
- Checkbox + ลิงก์ "อ่าน privacy notice" แยกกันชัดเจนตาม Design System หัวข้อ 3.2 (Membership/Consent Checkbox)
- เมื่อสมัครสำเร็จ (หรือข้าม) → กลับไปยัง State 2 เพื่อกดชำระเงินต่อ

## Wireframe — State 4: ผลการชำระเงิน (Payment Result)

### 4a. ชำระเงินสำเร็จ

```
+----------------------------------+
|                                    |
|                                    |
|         [ไอคอน ✓ success ใหญ่]      |  <-- เต็มจอ/modal ใหญ่ (block ความสนใจทั้งหมด
|          --color-success--        |      ตาม Design System หัวข้อ 4.4)
|                                    |
|        ชำระเงินสำเร็จแล้ว             |
|        --text-h1--                |
|                                    |
|     โต๊ะ #7 · ยอดชำระ ฿ 185         |
|     --text-body--                 |
|                                    |
|     ออเดอร์ของคุณกำลังถูกส่งไป        |
|     บาริสต้าเตรียมให้แล้ว             |
|     --text-caption--              |
|                                    |
|     (ถ้าเป็นสมาชิก) ได้รับแต้มสะสม     |
|     +18 แต้ม จากยอดนี้                |  <-- QR-03: คำนวณแต้มจากยอดชำระสำเร็จ
|                                    |
|  +------------------------------+ |
|  |         กลับไปหน้าเมนู          | |
|  +------------------------------+ |
+----------------------------------+
```

### 4b. ชำระเงินไม่สำเร็จ

```
+----------------------------------+
|                                    |
|                                    |
|         [ไอคอน ✕ error ใหญ่]        |  <-- เต็มจอ/modal ใหญ่
|          --color-error--          |
|                                    |
|       ชำระเงินไม่สำเร็จ               |
|       --text-h1--                 |
|                                    |
|   ระบบไม่สามารถตัดยอดชำระเงินได้      |
|   กรุณาลองใหม่อีกครั้ง                 |
|   --text-body--, --color-text-secondary-- |
|                                    |
|  +------------------------------+ |
|  |        ลองชำระเงินใหม่          | |  <-- กลับไป State 2 เพื่อลองจ่ายอีกครั้ง
|  +------------------------------+ |
|  [กลับไปแก้ไขตะกร้า]                 |
+----------------------------------+
```

- ทั้งสองกรณีแสดงผลแบบ **บล็อกความสนใจทั้งหมด** (full-screen) ตาม Design System หัวข้อ 4.4 เพราะเป็นสถานะที่กระทบเงิน/ธุรกรรม ไม่ใช่แค่ toast เล็กๆ
- เมื่อสำเร็จ → ระบบบันทึก audit log `payment.succeeded` แล้วส่งออเดอร์ไป KDS (`QR-04`, นอก scope UI ของหน้านี้) และคำนวณแต้มถ้าเป็นสมาชิก (`QR-03`)
- เมื่อไม่สำเร็จ → ระบบบันทึก audit log `payment.failed`
- ⚠️ **ประเด็นเปิดจาก requirement ต้นทาง**: การจัดการกรณีชำระเงินไม่สำเร็จ/ยกเลิกออเดอร์ยังไม่ระบุรายละเอียดชัดเจนในสเปค (ดู [[../../../01-requirements/01-spec/20260807-01-table-qr-ordering|table-qr-ordering]] หัวข้อ "ประเด็นที่ยังไม่ชัดเจน") — wireframe นี้แสดงเพียง "ลองชำระเงินใหม่/กลับไปแก้ไขตะกร้า" เป็นสมมติฐานชั่วคราวตาม [[../20260829-01-user-journeys#Journey 1: ลูกค้าสั่งกาแฟผ่าน QR Code|Journey 1]] ยังไม่ใช่ flow ที่ยืนยันแล้ว

## ประเด็นที่ยังไม่ยืนยัน (สืบทอดจาก requirement ต้นทาง — ยังไม่ใช่การตัดสินใจใหม่ของ prototype นี้)

- ช่องทางชำระเงินที่รองรับ (พร้อมเพย์/บัตรเครดิต/วอลเล็ต) ยังไม่ระบุ — wireframe นี้แสดงเพียงปุ่ม "ชำระเงิน" แบบรวม ไม่ได้ลงรายละเอียดหน้าเลือกช่องทางจ่ายเงิน
- การจัดการกรณีชำระเงินไม่สำเร็จ/ยกเลิกออเดอร์อย่างเป็นทางการยังไม่ระบุในสเปค — State 4b เป็นสมมติฐานชั่วคราวตาม Journey 1
- อัตราการสะสม/แลกแต้มสมาชิกยังไม่กำหนด — ตัวเลข "+18 แต้ม" ใน State 4a เป็นตัวอย่างสมมติเพื่อแสดง layout เท่านั้น ไม่ใช่อัตราจริง
